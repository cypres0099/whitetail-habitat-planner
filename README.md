# Whitetail Habitat Planner

A Codex skill for planning private land around mature white-tailed deer and teaching the scouting and hunting decisions that go with it. It synthesizes public Tony LaPratt interviews and materials with Missouri conservation guidance.

## Use in Codex

Copy this repository folder into your Codex skills directory as `whitetail-habitat-planner`. Invoke `$whitetail-habitat-planner` and add an aerial map, topo, or a property question. The skill opens the reference guide relevant to the task.

> Use $whitetail-habitat-planner to review this boundary and aerial. Give me a field walk, three site hypotheses, and the smallest project worth trying in year one.

The [source index](references/sources.md) links the material behind the skill and documents coverage. The guides can also be read directly on GitHub.
